## 直接观察

- 公开旧版在 dry-run、分页练习中分别委派一次子任务；主子会话均执行相同功能测试。其子任务重新加载了 Dev Harness Skill。当前版和修改前快照均不需要委派，功能测试各执行一次。
- 因此，减少委派、避免重复验证的大部分收益在本轮新增改动之前已存在。当前版相对公开旧版三项总耗时下降约 26.8%，不能全部归功于本轮新增规则。
- 相对修改前快照，当前版工具调用略少（39 → 36），累计报告 tokens 略多（378,884 → 387,457，约 2.3%），耗时并未改善。分页当前版额外读取了 Architect router；不能仅靠较少工具调用推断更快。
- 本轮三个任务均很短，没有触发 15/45 分钟检查点、耗尽修复预算或执行 Track 生命周期。因此尚未验证新增规则能否阻止原来长任务的范围扩张和无休止修复。
